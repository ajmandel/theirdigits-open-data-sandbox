# theirdigits open-data sandbox

An early interactive concept for discovering, combining, and learning from
openly licensed US and European datasets. The interface starts with a research
question, suggests plausible data ingredients and joins, surfaces licensing and
ethical constraints, and can generate a starter Jupyter notebook.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## What is in v1

- An AI-style project composer with a worked wearable/cell-tower example
- 52 seed datasets with prominent licence, access, messiness, and lesson labels
- Search plus subject, region, and licence filters
- A browser-generated Jupyter notebook scaffold
- Responsive layouts and social-preview metadata

The project-map response is currently a designed prototype, not a live AI call.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the vinext build output
- `npm test`: build and verify the rendered production HTML

Licence labels are educational summaries, not legal advice. Verify each source
record and its current terms before reuse or redistribution.
